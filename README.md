# Mega Villages Mod (Forge 26.1.2 / Minecraft 1.12.2)

Готовый Forge-мод под ветку Forge **26.1.2** (Minecraft 1.12.2).

## Готовый файл мода

После сборки файл:

`build/libs/megavillages-forge-26.1.2-1.0.2.jar`

## Как собрать

```bash
gradle clean build
```

## Установка

1. Установи Minecraft 1.12.2 + Forge 26.1.2.
2. Возьми jar из `build/libs`.
3. Кинь его в папку `mods`.
